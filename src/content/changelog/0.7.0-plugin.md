The plugin now ships **four** slash commands instead of seven, and runs on **GitHub Copilot CLI** as a fourth host. This release is breaking: five command names are gone.

## Breaking changes

- `/archcore:capture` and `/archcore:decide` are replaced by **`/archcore:document`**. The skill classifies your request and runs the decision track (`adr`, `rfc`) or the describe track (`spec`, `doc`, `guide`).
- `/archcore:audit` is replaced by **`/archcore:review`**, which adds a branch review on top of the old dashboard and audit modes. With no arguments on a branch that has changes, it compares the diff with `.archcore/` in both directions and verdicts each finding `spec-wrong`, `code-wrong`, or `ok`.
- `/archcore:context` is removed. The code-alignment injection already put the applicable documents in front of every source-file edit, so the manual command was a duplicate.
- `/archcore:help` is removed. Your host's `/archcore:` autocomplete lists the four commands.
- `/archcore:plan` takes a positional track name instead of `--track`. The tracks are `sdd` (idea → prd → spec → plan), `sources` (mrd → brd → urd), and `iso` (brs → strs → syrs → srs). The former `product` and `feature` tracks are folded into `sdd`.

## Improvements

- **GitHub Copilot CLI** is a supported host. Install with `copilot plugin install archcore-ai/plugin:plugins/archcore`, then wire the project with `archcore init --agent copilot --project "$PWD"`. Both steps are required: Copilot launches a plugin's MCP server with no project path, so the plugin ships none and the project-level entry is the only source of document tools.
- `/archcore:init` gains `--depth=light|standard|deep`, `--domain=<slug>`, and `--refresh`. It composes the whole first-day seed in one preview and creates it on a single confirm, and the same confirm installs host wiring.
- Agent instruction imports are finer-grained. Aggregate files (`CLAUDE.md`, `AGENTS.md`, `.cursorrules`) become link stubs, and modular rule files such as `.cursor/rules/*.mdc` become `rule` documents.
- Both built-in agents ship a third format, `.agent.md` under `copilot-agents/`, for Copilot CLI.

## Misc

- Hook policy moved into the Archcore CLI. The plugin's `bin/` scripts are now launchers that delegate to `archcore hooks <host> <event>`. They require CLI v0.7.0 or later and exit silently below it, so an older CLI cannot turn a usage error into a blocked edit.
- The `archcore-auditor` deny list now covers all seven mutating MCP tools, including `init_project` and `install_host_config`.
