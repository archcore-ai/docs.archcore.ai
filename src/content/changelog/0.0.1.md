Archcore gives your AI coding agents structured, typed context about your project: decisions, rules, plans, and patterns. Agents read that context through the MCP server while they work.

![Archcore CLI in action](/changelog/cli-init-light.png)

## What's included

- 10 document types (ADRs, RFCs, Rules, Guides, Plans, and more), each with its own template, across three layers: Knowledge, Vision, and Experience
- 8 supported agents: Claude Code, Cursor, GitHub Copilot, Gemini CLI, Codex CLI, OpenCode, Roo Code, and Cline, with auto-detection and one-command setup
- An MCP server with 8 tools: agents list, read, create, and update documents through the Model Context Protocol
- CLI commands for your `.archcore/` directory: `init`, `validate`, `doctor`, `config`, `mcp`, `hooks`, and `update`
- Local-first and Git-friendly: `.archcore/` lives in your repo, so Git versions it with your code

## Get started

```bash
curl -fsSL https://archcore.ai/install.sh | bash
cd your-project
archcore init
```
