This release aligns the plugin with the CLI's [global sources](/cli/global-sources/) feature. Two failure modes that used to be silent now produce guidance at session start.

## Improvements

- When an older, pre-globals CLI rejects the new `globals` field in `settings.json`, the session-start hook shows a one-time, rate-limited "update your CLI" advisory with install commands. Earlier, MCP and context were silently unavailable.
- The advisory fires only on the strict parser's exact field-rejection signature, so a current CLI that understands `globals` never triggers a false advisory, even in projects that declare globals.
- With a current CLI, a missing declared global degrades to a local-only context summary. The warning names the missing source, so local documents are never silently dropped.

## Misc

- Version bumped to `0.4.10` across the Claude Code, Cursor, and Codex CLI plugin manifests.
- Added CLI-compatibility invariant tests and unit coverage for the session-start advisory.
