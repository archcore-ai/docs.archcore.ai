The `research` path of `/archcore:plan` changes what it produces, one external material can be filed as an `evidence`, and Cursor document writes receive the same post-write advisories as the other hosts.

## Breaking changes

- `/archcore:plan research <topic>` produces a `research` document, an open investigation closed by coverage of its declared scope. Before this release the path produced an `rnd`. To get an investigation that ends in a recommendation, name the type: `/archcore:plan rnd <topic>`.

## Improvements

- `/archcore:plan rnd <topic>` runs the investigation path with the type fixed to `rnd`. Without a named type, a request that names a pending decision or a set of candidates produces an `rnd`; any other investigation produces a `research`.
- `/archcore:plan evidence <material>` and `/archcore:document evidence <material>` file one external material as an `evidence`. The document and its first `supports` or `contradicts` edge are written in the same step. `/archcore:document research <report>` files a ready investigation report.
- The `supports`, `contradicts`, and `supersedes` relations are available on CLI v0.8.3 or later.
- On an older CLI, `/archcore:plan research` falls back to `rnd` and names the required version.
- The `/archcore:review` closeout scope includes `research` documents when the CLI supports them.
- Subagents can call `search_documents` and page through truncated inventories.
- `/archcore:init` help lists the `--domain=<slug>` flag.

## Fixes

- Cursor document writes receive validation, cascade, and precision advisories after MCP calls.
- Session start no longer breaks when the temp directory is unwritable.
