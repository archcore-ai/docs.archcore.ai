Installing the MCP server gives agents the tools but not the instruction to use them. Archcore now writes a short "use Archcore" hint into each detected agent's instruction file, so agents call the document tools during a session.

## Improvements

- New `archcore instructions install` writes the "use Archcore" hint into detected agents' instruction files (`AGENTS.md`, `GEMINI.md`, `.claude/rules/`), so agents call the MCP tools.
- New `archcore instructions remove` strips the hint, even after the project has been de-initialized.
- `archcore init` now offers to add the hint after agent setup (opt-in, default yes); non-interactive runs skip it and point to `archcore instructions install`.
- New `--agent <id>` flag on both subcommands targets a single host instead of all detected ones.
- Archcore edits shared files (`AGENTS.md`, `GEMINI.md`) inside a managed `<!-- archcore:start -->` marker block, so it can update or remove the hint without touching your own content.
