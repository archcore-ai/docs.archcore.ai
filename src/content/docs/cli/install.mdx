The CLI is a single binary. Install it with one command for your platform.

## Install

<Tabs>
	<TabItem label="macOS / Linux">
		```bash
		curl -fsSL https://archcore.ai/install.sh | bash
		```
	</TabItem>
	<TabItem label="Windows">
		```powershell
		irm https://archcore.ai/install.ps1 | iex
		```

		The script installs `archcore.exe` under `%LOCALAPPDATA%\Programs\archcore` and adds it to your user `PATH`. Open a new PowerShell window after install to pick up the `PATH` change. The script requires PowerShell 5.1 or later, which ships with Windows 10 and 11.
	</TabItem>
	<TabItem label="Windows (WSL)">
		If you prefer a Linux environment on Windows, install <a href="https://learn.microsoft.com/en-us/windows/wsl/install" target="_blank">WSL</a> and run inside it:

		```bash
		curl -fsSL https://archcore.ai/install.sh | bash
		```
	</TabItem>
</Tabs>

## Install options

The install scripts accept three environment variables (same on Unix and Windows):

| Variable               | Default (Unix)    | Default (Windows)                       | Purpose                                                                  |
| ---------------------- | ----------------- | --------------------------------------- | ------------------------------------------------------------------------ |
| `ARCHCORE_VERSION`     | latest            | latest                                  | Pin to a specific release tag (e.g. `v1.0.0`).                            |
| `ARCHCORE_INSTALL_DIR` | `~/.local/bin`    | `%LOCALAPPDATA%\Programs\archcore`      | Override the install directory.                                          |
| `GITHUB_TOKEN`         | None              | None                                    | Authenticate API and download requests (private repos, rate limits).     |

<Tabs>
	<TabItem label="macOS / Linux">
		```bash
		ARCHCORE_VERSION=v1.0.0 ARCHCORE_INSTALL_DIR=/usr/local/bin \
		  curl -fsSL https://archcore.ai/install.sh | bash
		```
	</TabItem>
	<TabItem label="Windows">
		```powershell
		$env:ARCHCORE_VERSION = 'v1.0.0'; $env:ARCHCORE_INSTALL_DIR = 'C:\tools\archcore'
		irm https://archcore.ai/install.ps1 | iex
		```
	</TabItem>
</Tabs>

## Verify

```bash
archcore --version
```

You should see a version string. If the binary isn't on your `PATH`, see [CLI troubleshooting](/cli/troubleshooting/).

## Update

```bash
archcore update
```

`archcore update` queries the GitHub release feed, downloads the binary for your OS and architecture, verifies the checksum, and updates in place.
