The CLI is a single binary. Install it with one command for your platform.

Prebuilt binaries cover `darwin`, `linux`, and `windows` on `amd64` and `arm64`. On any other target, build from source with `go install github.com/archcore-ai/cli@latest`.

## Prerequisites

- macOS and Linux: `bash`, `curl`, `tar`, and `sha256sum` or `shasum`. The script runs under bash, not POSIX `sh`. On a minimal distribution such as Alpine, install the missing pieces first with `apk add bash ca-certificates`.
- Windows: PowerShell 5.1 or later, which ships with Windows 10 and 11.

## Install

<Tabs>
	<TabItem label="macOS / Linux">
		```bash
		curl -fsSL https://archcore.ai/install.sh | bash
		```
	</TabItem>
	<TabItem label="Windows">
		```powershell
		irm https://archcore.ai/install.ps1 | iex
		```

		The script installs `archcore.exe` under `%LOCALAPPDATA%\Programs\archcore` and adds it to your user `PATH`. Open a new PowerShell window after install to pick up the `PATH` change.
	</TabItem>
	<TabItem label="Windows (WSL)">
		If you prefer a Linux environment on Windows, install <a href="https://learn.microsoft.com/en-us/windows/wsl/install" target="_blank">WSL</a> and run inside it:

		```bash
		curl -fsSL https://archcore.ai/install.sh | bash
		```
	</TabItem>
</Tabs>

Each script downloads the release archive and `checksums.txt`, and verifies the SHA-256 checksum before installing.

## Install options

The install scripts accept five environment variables (same on Unix and Windows):

| Variable                    | Default (Unix)    | Default (Windows)                       | Purpose                                                                  |
| --------------------------- | ----------------- | --------------------------------------- | ------------------------------------------------------------------------ |
| `ARCHCORE_VERSION`          | latest            | latest                                  | Pin to a specific release tag (e.g. `v1.0.0`).                            |
| `ARCHCORE_INSTALL_DIR`      | `~/.local/bin`    | `%LOCALAPPDATA%\Programs\archcore`      | Override the install directory.                                          |
| `GITHUB_TOKEN`              | None              | None                                    | Authenticate asset downloads from a private repository. Version resolution reads a public redirect and uses no token. |
| `DO_NOT_TRACK`              | None              | None                                    | Any value other than `0` disables install analytics.                     |
| `ARCHCORE_TELEMETRY_OPTOUT` | None              | None                                    | Any value other than `0` disables install analytics. Tool-specific equivalent of `DO_NOT_TRACK`. |

<Tabs>
	<TabItem label="macOS / Linux">
		```bash
		ARCHCORE_VERSION=v1.0.0 ARCHCORE_INSTALL_DIR=/usr/local/bin \
		  curl -fsSL https://archcore.ai/install.sh | bash
		```
	</TabItem>
	<TabItem label="Windows">
		```powershell
		$env:ARCHCORE_VERSION = 'v1.0.0'; $env:ARCHCORE_INSTALL_DIR = 'C:\tools\archcore'
		irm https://archcore.ai/install.ps1 | iex
		```
	</TabItem>
</Tabs>

## Install analytics

The installer sends one anonymous event per run: `cli_installed` on success, or `cli_install_failed` with a stage category on failure. The event carries no error text, no file paths, no user or host names, and no repository data. The installed CLI binary sends nothing; only the installer reports.

The event's identifier is a random value stored at `${XDG_STATE_HOME:-$HOME/.local/state}/archcore/install-id` on Unix and `%USERPROFILE%\.local\state\archcore\install-id` on Windows. The installer prints a one-line notice when it sends the event.

Opt out by setting `DO_NOT_TRACK=1` or `ARCHCORE_TELEMETRY_OPTOUT=1`. The scripts check the opt-out before creating the identifier file, so an opt-out leaves no trace on disk:

```bash
DO_NOT_TRACK=1 curl -fsSL https://archcore.ai/install.sh | bash
```

The full policy is at <a href="https://archcore.ai/privacy" target="_blank">archcore.ai/privacy</a>.

## Verify

```bash
archcore --version
```

You should see a version string. If the binary isn't on your `PATH`, see [CLI troubleshooting](/cli/troubleshooting/).

## Update

```bash
archcore update
```

`archcore update` reads the latest release tag from the `https://github.com/archcore-ai/cli/releases/latest` redirect (no GitHub API request), downloads the binary for your OS and architecture, verifies the checksum, and replaces the binary in place. The [`archcore update` reference](/cli/commands/#archcore-update) covers the `--check` flag.

Two other paths update the binary: re-run the install script, or run `go install github.com/archcore-ai/cli@latest`.
